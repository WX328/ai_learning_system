# 知行前端

## 工作台视觉样式

`workspace.css` 在原组件样式后加载，集中管理字体、颜色、间距和手机布局。`workspace.js` 只管理收起式导航的展示、键盘焦点和背景隔离，页面切换继续使用 `core.js`。统一线性图标位于 `icons.svg`，Instrument Sans 字体和 OFL 许可在 `fonts/`，运行时不请求字体 CDN。

桌面采用冷灰框架与白色正文，1100px 以下收起侧栏，手机优先显示继续学习或已有教练会话。原 API、练习进度和业务规则沿用。视觉截图、检查结果和隔离预览说明见 [公开截图与隔离验证来源](../docs/portfolio/README.md)。

## 百炼向量与资料重建

项目使用百炼 `text-embedding-v4` 生成资料和问题向量，因此启动后不再加载本地 Hugging Face 模型。复制根目录的 `.env.example` 内容到本地 `.env`，填写 `DASHSCOPE_API_KEY` 与业务空间对应的 `DASHSCOPE_EMBEDDING_BASE_URL`。默认使用 1024 维向量，可通过 `DASHSCOPE_EMBEDDING_MODEL` 和 `DASHSCOPE_EMBEDDING_DIMENSIONS` 调整。

切换模型或向量维度后，旧向量不能继续使用。在资料库的每份资料卡片点击“重建向量”，确认后才会调用百炼：每批最多处理 10 个文本片段，保留已有知识点关联，并在全部向量成功返回后一次提交数据库更新。若百炼请求失败，旧向量保持不变。资料分段内容和原记录不一致时，系统会停止重建，避免悄悄丢失知识点关联。

沿用 FastAPI 的静态文件托管方式：启动原项目后，访问服务的 `/app` 路径。无需 npm 安装或构建；请通过 HTTP 访问，勿直接双击 HTML（使用原生 ES modules）。更新后可用 Ctrl + F5 强制刷新。

## 知识点问答与旧资料兼容

选择知识点后，所有问法都会向模型说明当前知识点，“不知道这个知识点”等省略名称的问题也能获得针对性解释。“总结当前知识点”和“举一个例子”的快捷问题会带上该知识点的名称。正文不超过上下文片段数时，直接按章节顺序读取，不调用向量或重排服务；较长的知识点按当前知识点名称和原问题检索，未命中或向量服务不可用时使用该知识点的已知正文。引用区会如实标注“知识点正文片段”或实际检索方式。

回答仍由原有模型根据正文生成，可提供明确标注为教学示例的生活类比和代码，不能把补充示例说成资料原文。真正缺少正文时仍会提示缺少依据；不会使用其他知识点或其他资料的正文冒充当前知识点依据。

旧索引中一个片段可能包含多个知识点。检索会补充匹配正文中明确出现的知识点名称，尽量只提供相关章节，因此不必重新导入或重建向量。没有关联正文且找不到名称时，仍提示资料不足，不会混用其他资料。新导入的 Markdown 按章节切分；旧资料重建向量时保留原分段、引用 ID 和知识点关联。

## 新增学习功能

- 首页成长卡：账户累计 XP、等级、升级进度、首次作答正确率和待巩固错题数。
- 错题本：首次答错的题目自动收集；支持资料、关键词、复习状态筛选和分页，展开原答题解析，在对话框中重新练习。
- 学习记录：服务端保存的问答、首次答题、错题复习和其他学习记录；支持关键词、活动类型及本地日期筛选。
- 知识地图：资料到知识点的层级展示，显示说明、规则掌握度和关联文本数，点击进入对应问答或练习。未练习单独标记，80 分及以上标记为规则达标，评估依据可展开查看。

新页面由 `study.js` 实现，使用 `/study/summary`、`/study/mistakes`、`/study/records`、`/study/map` 接口；复习提交使用 `/study/mistakes/{question_id}/review`。所有接口按登录账户隔离。`review_attempts` 表随原有 FastAPI 启动建表流程创建，无需重建数据库。未使用自动重载的服务需重启，再用 Ctrl + F5 刷新页面。

复习记录在服务端持久保存，独立于首次答题；不重复奖励 XP。同一次保存重试使用同一请求 ID。S2 每题采用首次答案与最新复习结果的有限加权，复习不增加样本；统一结合历史、最近 5 道不同题目、难度和样本平滑计算规则掌握度，供地图、推荐和教练共同使用。首页首次作答正确率仍只统计首次答题。详见 [S2 算法说明](../S2_TOPIC_MASTERY.md)。

知识地图会提示未关联文本的知识点，并提供整份资料问答入口。本次未自动重新分类历史资料或调用付费模型。连线仅表示包含关系，不表示先修关系。历史记录时间不改写，新答题、问答和学习记录使用实际创建时间；没有真实计时的数据不显示为学习时长。

验证命令（在项目根目录）：

```text
python -m unittest discover -s tests -v
node --experimental-vm-modules tests/frontend_study.mjs
```

后端测试使用独立内存数据库；前端测试以 DOM 事件模拟验证模块链接、交互、错误恢复和会话清理，不替代真实浏览器视觉测试。

## 文件职责

- `index.html` / `styles.css`：资料库、问答、练习、导入和认证页面，含移动端布局。
- `core.js`：共享状态、请求、会话注销、通知与页面切换。
- `materials.js`：资料检索、预览、当前资料选择、知识点加载。
- `chat.js`：按资料加载问答历史、知识点范围、回答复制及安全的基础 Markdown 展示。
- `practice.js`：知识点出题、自适应推荐、提交锁定、当次练习总结。
- `upload.js`：文件/文本导入，逐文件阶段提示，以及保存、索引、知识点整理阶段的失败重试。
- `app.js`：模块初始化及登录/注册。
- `home.js`：继续学习、待完成题组、最近问答和本地记录清除入口。
- `progress.js`：按账号保存、校验、恢复浏览器中的练习快照。

## 与现有后端的约定

上传接口的 `title`、`material_type` 通过查询参数传递，文件通过 multipart 表单传递。问答在选中知识点时传入真实 `topic_id`；S4 起普通出题必须先选择已提取的知识点并传入有效 ID，服务端和保存层也会校验。历史无关联题目仍可作答，不猜测其知识点。

资料创建和上传现在按账号、正文内容去重（统一换行符及首尾空白/BOM，不抹去正文内部缩进）。重复提交返回已有资料及 `reused`、`indexed`、`has_topics` 状态，前端跳过已完成的准备阶段。服务端以 SQLite 短事务串行执行查重和插入，避免并发新增重复资料。

资料列表将已有相同内容只显示一份，优先选取已建立索引和知识点的记录。`duplicate_ids` 保留旧资料 ID 的关联；问答可回看同组旧资料历史，首页可继续旧 ID 下保存的练习。同名但内容不同的资料不会合并，选择器显示内容版本 ID。资料卡片的“删除”会先二次确认，再永久删除该可见资料及其隐藏重复副本，同时清理关联的文本片段、知识点、问答、题目、答题/复习记录和浏览器内对应练习快照；账户 XP、等级和成就保留。

## 当前边界

- 问答支持标题、粗体、行内代码和围栏代码块，不渲染原始 HTML，不额外加载 CDN。
- 问答接口仍为单次请求；历史展示不代表向模型传入多轮对话。
- 每份资料最近一组题目、当前选项、已确认的答题结果和所在题号按账号保存在当前浏览器的 localStorage。刷新、退出后同账号重新登录均可恢复，不跨浏览器、设备或站点地址同步。新题组成功生成后替换该资料旧题组；并非完整的历史错题本。
- 首页展示最近资料、未完成练习和服务端问答历史；首页本地答题数量仅统计保留题组，不代表账号累计答题量。
- 请求处理中或自动保存失败时，离开页面有浏览器提示。如果提交答案期间刷新，恢复后标记结果待确认；重试遇到服务端“已经回答”时，本地不猜测对错或经验值，并允许继续下一题。服务端未提供逐题历史查询，因此这些题目不计入本地正确率。
- 手机宽度下有题目时默认收起练习设置，提供展开按钮和随作答区滚动的底部提交/下一题操作栏。
- 上传失败可在当前窗口重试，已成功完成的保存和索引阶段不会主动重做。网络中断时，服务端是否已提交仍取决于现有接口；跨刷新恢复及请求幂等性需后端支持。
- 自适应入口复用 `/adaptive/next-question`。无推荐时显示引导，先做关联知识点的普通练习。
- 退出登录会中止未完成请求并清空账号相关页面数据，本地练习保留供同账号恢复。首页可确认清除本账号的本地练习，服务端答题记录与经验值不受影响。最近选择的资料 ID 也按账号保存，不保留资料正文；本地题组含题目文本与已返回的解析。

已用隔离模拟接口执行浏览器流程验证，涵盖注册、资料检索/预览/切换、历史、知识点参数、答题锁定/总结、自适应返回/空状态、上传重试、手机布局及注销清理。未调用真实模型或写入学习数据库。
